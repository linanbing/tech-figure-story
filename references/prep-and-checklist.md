# 备料清单 / 选题结合 / 兜底选题 / 自查清单

本文件为 `tech-figure-story` 技能的参考资料，成稿前按需加载。

## 一、素材清单（写前必读，人物/企业二选一）

### 人物模式
1. 早期经历：求学、转折、低谷（年份、事件、原话）
2. 关键里程碑：产品/技术/融资节点，带数字和日期
3. 金句集：访谈、演讲、路演原话 5-10 条
4. 他人评价：投资人、同行、媒体的有出处评价
5. 争议与反差：至少 1 个反差点（用本人回应处理）
6. 画面细节：某个公开场合的表情、动作、对话
7. 生活侧面：有公开报道的可用，没有就跳过

### 企业模式
1. 成立背景：创始人动机、团队构成、第一笔融资（或第一单生意）
2. 关键里程碑：产品发布、大客户、融资轮次，带数字和日期
3. 至暗时刻：濒死经历、重大失败、危机（必须有公开出处）
4. 转折点：哪件事让公司活下来/跑出来
5. 商业模式与护城河：怎么赚钱、别人为什么追不上
6. 财务与规模数据：营收、市占、估值，注明口径
7. 创始人金句与外部评价：原话优先
8. 争议：舆论质疑、行业争论（用公司回应带过）

## 二、选题与热点结合（优先规则，写前必读）

**选题第一原则：跟着热点走，不要凭清单挑。**

1. 写之前先确定当前最热的事件：查询今天的 AI 圈头条（新模型发布、公司上市、融资、政策、爆款产品、行业大事件）。
2. 从热点事件里逆推主角：这个事件涉及哪个模型/公司/人物？按优先级选——事件主角 ＞ 直接相关方 ＞ 同赛道对标玩家。
3. 只有热点事件没有合适的主角时，才退回「可复用选题清单」。

**注意**：这里说的「热点」≠ 时效压力。借热点的流量讲人物/企业的长期故事，新闻是钩子，故事才是主体。今天的热点只是引流入口，故事本身不要求当日发出。

**优先级排序（按推荐程度）**：
1. 热点事件中的主角：新模型背后的团队/公司/创始人（如某模型刷榜，写它背后的人）
2. 热点事件的直接相关方：被收购方/投资方/竞争对手/产业链上下游
3. 热点事件的对标物：让读者理解热点时绕不开的参照物（如新模型发布，旧王者是怎么崛起的）
4. 可复用选题清单：热点没有适合的主角时再用

## 四、自查清单（交稿前过一遍）

**选题层（新增）**
- [ ] **防重已过？**（选人前必做：① 读 `已写选题台账.md`；② `python tools/check-topic-dup.py --today`；③ `python tools/check-topic-dup.py <候选主角>`。命中即换人，**不接受「凭印象觉得没写过」**。已发生：杨植麟 8/20+9/7、李飞飞 8/21+9/2 各重写一次）
- [ ] **同日幂等已判？**（`--today` 返回 1 时：今日稿达标 → 本次直接结束、输出「今日已完成」；不达标 → 只补全同一篇，**不得换人新写**。一天一篇、一篇一人。张一鸣 9/30 同日被写两遍就是这个口子）
- [ ] **定稿后已回写台账？**（把主角追加到 `已写选题台账.md` 主表末尾一行；漏写 = 下次必重复）
- [ ] 主角有一个「差点没撑住」的公开事实（健康/资金/被放弃/延毕/争议），且有公开出处？（搜不到 → 换人，别硬写）
- [ ] 主角是已知人物（出圈过）时，是否已改用反常识角度切入，而非「他凭什么」式结局悬念？（彭志辉篇教训：第二段亮出「B站几百万粉丝叫他野生钢铁侠」，悬念当场失效）

**标题层（新增）**
- [ ] 标题没把结局写进去？（身份+动作+结果三件套齐全 = 废标题；张建中篇教训「54岁从英伟达全球副总裁转身，去造最难的国产GPU」——读者看完标题能复述主角结局，就重写。标题只留身份+反常动作/悬念数字，把「为什么」留给正文）

**数字层（新增，量化红线）**
- [ ] 全篇数字密度 ≤ 25 个/千字？（脚本统计；超衍篇 21.1 安全区，张建中篇 50.9 翻车）
- [ ] 单段数字 ≤ 3 个？（由 4 收紧；数据密集事件只留 2-3 个核心数字）
- [ ] 亏损明细 / 逐年增速 / 解禁比例 / 小数点后两位股价，是否只留了一个代表值、其余已删？

**排版层（新增，硬线）**
- [ ] 小标题 6-8 个，每 400 字一个？（彭志辉篇 2537 字只有 1 个小标题 = 最致命排版问题）
- [ ] 小标题为疑问句或动作句，无编年目录式（「1990 到 2020」「三十五年，从实验室到敲钟台」）？
- [ ] 单段 ≤ 250 字，最长段 ≤ 300 字？（脚本量段长，超线拆段）
- [ ] **逐节体量均衡？**（脚本逐节量字数。AI 写稿最典型的退化是：时间跨度大、事实密度低的那一节，被自动压成产品/事件罗列——读起来就是「一节成了 PPT 要点」。张一鸣篇教训：第五节「巅峰时，他转身退到幕后」承担 2021→2026 五年跨度，却只有 234 字、三句产品罗列（火山引擎 / 扣子 2.0 / Seedance 2.5），而同篇其他节 271/273 字，落差即读者说的「薄」。判据：**任一节字数低于同篇各节中位数的 70% 即视为「薄」**。补法：把罗列砍成一句，腾出的字数换成**一个人物动作或一句主角原话**，不要补成更长的产品清单）

**基础项**
- [ ] 明确标注了模式（人物/企业）？
- [ ] 正文字数达到 2800 以上？（不达标明确说明差多少，不硬凑）
- [ ] **自查清单里引用的每一个数字，都是脚本实测的吗？**（字数、数字密度、最长段、出现次数，一律跑脚本；**禁止估算、禁止沿用上篇结论、禁止凭印象勾选**。张一鸣篇教训：自查写了「正文约 3000 字 / 数字约 7.3 个千字 / 单段 ≤3 个」，实测为 1606 字 / 21.2 个千字 / 有 3 段是 4 个数字——三条全错，自查反而成了「造假掩护」。自查行里的每个数字后面都应能复现出那条命令）
- [ ] 通读检查：有没有禁用词清单里的词？（出现 3 处以上重写）
- [ ] 事实都有公开出处？（涉及事实的每句都能指出来源）
- [ ] 有没有编造的细节、对话、心理活动？
- [ ] 数据口径是否注明？（盘中/收盘、年份、占比）
- [ ] 短句为主、一句一段？
- [ ] 有没有网文腔、公文腔、AI 模板句？
- [ ] 排版是否符合公众号规范？（顶格、段长、重点句独立成段、图注）；图注是否合规：AI 示意图带「（示意）」标注、非新闻现场式陈述、未复读正文原句（只描述画面或补正文没有的信息）？
- [ ] 结尾是否回到开头画面形成闭环？
- [ ] 高危词（「XX第一」「史上最」）是否已弱化？
- [ ] 互动钩子是否自然？是否回扣主题词且句式有跨篇变化（「你身边有…的人」万能句式未连续两篇复用；优先绑本篇独有决策 / 情境提问，而非每次盘点身边的人）？
- [ ] 开场场景有无出处？无出处的已标注「创作演绎」或替换成真实场景？
- [ ] 所有相乘 / 相加得出的数字，已重新核对运算？
- [ ] 单段数字是否 ≤3 个？数据密集事件是否只留 2-3 个核心数字（其余删除或括号备注）？
- [ ] 股价 / 市值 / 估值类数字是否标注时点（上市首日 / 历史最高 / 某交易日）？三者有无混写？来源分不清时点的是否已改定性表述？
- [ ] 全篇主题词是否唯一且限频？（升华句列出来，是否只回一个词；核心词含同义变体全篇≤4-5 次，超限已换轮换词或删重复句）
- [ ] 引号是否全篇「」？（无英文弯引号混用）
- [ ] 「不是X是Y」出现次数是否 ≤2？
- [ ] 标题是否按出圈分层处理？（国民级人物人名放标题、禁止隐藏；圈内人物用悬念数字/外号/身份标签替代、人名正文首段揭晓；外号优先须有公开传播基础，且圈内人物标题所用数字仍满足「标题数字须有出处」）
- [ ] **标题数字有出处？**（标题 / 首屏的卖点数字必须能指出来源，圈内人物用的悬念数字同样须有公开出处，查不到就换；参考事实纪律第 9 条）

## 五、示例（已实践验证，供对照）

### 示例一：王兴兴（宇树，人物模式）
- 场景：2026.08.19 七夕敲钟，「冷静哥」表情，午宴才笑
- 悬念：一个英语几乎没及格过的人，凭什么？
- 三件事：①实验室偏科少年（200 元机器人 → 考研落榜 → XDog 延毕半年）②50 平办公室抠门哲学（天使投资未签协议 → 账上 10 万 → 大疆错失百亿）③路演台不解释（遥控玩具质疑 → 春晚秧歌 → 超人跳高 2 米）
- 规律：专注、成本、不解释
- 名言：「你 24 小时一直在思考一个问题，我不信问题解决不了。」
- 收尾：不是天才逆袭，是偏科少年把一件没人在乎的事做了快二十年
- 钩子：你身边有这样的人吗？欢迎留言聊聊。

### 示例二：公司通用骨架（企业模式）
- 场景：至暗时刻的办公室 / 融资公布日 / 产品发布现场
- 悬念：一家快要活不下去的公司，凭什么走到了今天？
- 三件事：①出生（创始人动机、第一笔钱）②至暗（濒死、失败、被质疑）③破局（转折点、做对了什么）
- 规律：护城河一句话（例：别人拼速度，它拼成本和供应链）
- 名言：创始人原话
- 收尾：回扣开头画面 + 反差句
- 钩子：你经历过类似的至暗时刻吗？欢迎聊聊。
