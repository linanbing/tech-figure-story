# tech-figure-story

> 一套用于产出「有温度、有画面、有传播力」的微信公众号故事型长文的写作引擎。

写 AI 人物、AI 公司、AI 事件的公众号推文专用。内核是经得起查证的真实人物/公司/事件，外壳是情感号成熟的叙事手法。

**一句话原则：读者记住的不是信息，是情绪和画面。**

情感号写夫妻相处，这套技能写人物成长与企业沉浮。公式不变，内容换壳。

---

## 这是什么

一个 [Claude Code / WorkBuddy](https://www.workbuddy.cn) Skill —— 把「怎么把一个科技人物写成一篇让人愿意读完并且转发的公众号文章」这件事，沉淀成一份可执行、可机械自检的规则文件。

不是提示词技巧集合，是一份**带红线的操作手册**：每条规则都来自一次真实的翻车。

## 核心：七步公式

| 步骤 | 做什么 | 要点 |
|---|---|---|
| **1 · 现场切入** | 有画面感的场景开头 | 给具体细节：时间、地点、动作 |
| **2 · 抛悬念** | 埋一个读者会好奇的问题 | 已知人物须换反常识角度 |
| **3 · 三个故事** | 三个最能塑造主角的节点 | 完整小故事，禁碎片堆砌 |
| **4 · 归规律** | 点破核心方法 | 「点破」不是「总结」，禁自指词 |
| **5 · 垫名言** | 本人原话收口 | 优先原话，不用通用名言 |
| **6 · 收尾回扣** | 回到开头场景 | 有分量，不煽情 |
| **7 · 转化收尾** | 关注理由 + 下期预告 + 互动钩子 | 按粉丝量分档配置 |

## 三种模式

| | 人物志 | 公司故事 | 事件故事 |
|---|---|---|---|
| **主角** | 一个人 | 一家公司 + 一个「人肉锚点」 | 一个事件 + 深夜拍板的人 |
| **主线** | 人物弧光 | 锚点人物的决策时刻 | 引爆 → 转折 → 余波 |
| **悬念** | 他凭什么能成？ | 当年那人为什么敢下注？ | 谁在深夜拍了板？ |
| **时效** | 不限 | 不限 | 24–48 小时内 |
| **字数** | 2800–3200 | 2800–3200 | 1500–2000（快闪版） |

**公司故事硬规则**：必须先挖出该公司历史上最具戏剧性的真实人物及其一个决策时刻作为叙事主轴。公司只是舞台，不抢戏。找不到合格锚点，宁可不写。

**事件故事硬规则**：主线必须是「谁在深夜做了什么决定」，禁止写成融资公告 / 产品发布稿的翻译稿。

## 几条最容易被 AI 写坏的纪律

这套技能的存在意义，很大程度上是堵 AI 写作的洞。以下都是实战踩出来的：

**1. 数字必须能指到出处**
标题里最扎眼的数字，恰恰常常查无出处（例：「37 家拒投」）。凡「年龄 / 数字 + 人」的组合，一律回查来源清单——**捏造的数字最爱藏在抒情句里**，因为人读时会下意识跳过。

**2. 量级词要算一遍**
「等了二十一个月」——把两个日期取出来一算只有 9 个月。凡「等了很久 / 做了很多 / 有几百人」这类词，先把对应数字取出来算一遍。

**3. 数字密度有红线**
- 全篇：每千字数字 ≤ 25 个（超了就是数字墙，故事变财报）
- 单段：数字 ≤ 3 个
- 计数口径必须先声明（完整日期整体计 1 个 vs 年/月/日拆分计 3 个，会算出差异极大的密度）

**4. 跨口径数字禁并置**
集团 vs 子公司、人民币 vs 美元、2023 计划 vs 2026 估值——口径不一致的数字放在一起做因果对比，就是误导。

**5. 演绎场景必须标注**
吃豆汁儿、蹲路边吃面这类开场最抓眼也最危险。无公开出处的场景细节必须标注「以下场景为创作演绎」，或换成有据的真实场景。

**6. 收口禁自指**
「把这三段连起来看」「我看到的不是…而是…」——作者跳出来点明自己的叙事手法，立刻露机器味。规律要靠事实递进自己长出来。

**7. 「不是X，是Y」全篇 ≤ 2 处**
一旦超过，作者一忍不住想升华，这个句式就现形。总结段尤其密集爆雷。

## 禁用 AI 味用词（节选）

- **概括性大词**：赋能、抓手、闭环、链路、底层逻辑、认知、颗粒度、对齐、复用、范式、颠覆、重塑
- **万能转折**：值得注意的是、不难发现、毋庸置疑、显而易见、在……的今天、划时代、里程碑式
- **空洞情绪词**：魅力、力量、传奇、精神内核、深邃、厚重、熠熠生辉、奏响、谱写
- **废话开头**：随着人工智能的快速发展、在科技飞速发展的背景下、近年来

**检验标准**：读者能闻出机器味的套话。真人写作检验——这句话你会不会对朋友这么说？不会，就删。

## 排期约定

自动化每日运行时，按星期锁定主线模式：

| 星期 | 主线 | 主角类型 |
|---|---|---|
| 一 / 三 / 五 / 日 | 人物志 | 一位 AI 人物 |
| 二 / 四 / 六 | 公司故事 | 一家公司 + 锚点人物 |
| 每日轮询 | 事件故事 | 命中热点即生成（可与主线叠加，同日出两篇） |

记忆口诀：**一三五七人物志、二四六公司故事、事件轮询随时补**。

地域偏好：**优先中国选题**。这不是硬豁免 —— 事实纪律、禁用词、防重、标题数字出处等所有规则照常生效。

**系列优先（覆盖星期轮询）**：当一个系列已有 ≥2 篇、且其中一篇阅读量 ≥ 账号均值 5 倍时，暂停星期轮询，连续把该系列写完 —— 系列未完前，主线和事件轮询都让路。算法需要连续同题材内容才能收敛出稳定标签，系列跑通一篇就断等于把刚点着的推荐池浇灭。

防重靠专门的「已写选题台账.md」，不是日志（日志只保留最近一次运行，跨天不累积，当成「已覆盖清单」读永远读到空的）。已发生过三次真实重复事故（杨植麟 8/20 与 9/7、李飞飞 8/21 与 9/2、张一鸣 9/30 同日重跑）。
